# 产品功能地图
【按需创建】首次出现以下任一触发条件时创建：①"大切小"切出了排队的部分 ②讨论中识别到一个新的独立功能模块。之后持续维护，不要求一次性列全。

## 模块清单
| 模块名 | 一句话描述 | 状态 | 来源 | 备注 |
|---|---|---|---|---|
| <示例：会员积分> | <一句话> | 深度定制中 / 占位-标准实现 / 未来迭代 / 待评估 | 大切小切出 / 讨论中识别 / 外部材料导入 | |

**状态说明：**
- 深度定制中：正在或即将走完整的需求→设计→开发流程
- 占位-标准实现：不值得展开讨论，开发时按行业惯例给个够用的实现，不深挖
- 未来迭代：明确排在后面，暂不处理
- 待评估：刚识别出来，还没和用户确认要不要做/怎么做

**使用方式：**
- 新增模块：AI识别到后先给一句话描述，等用户确认再写入本表，不擅自写入
- 不要求本表完整或"聊完"才能开发——挑一个"深度定制中"的模块走Skill A/B/C即可，其余模块保持原状态不受影响
- 开始处理某个具体功能前，Skill A会用本表"已确认模块"做定位提示；这只是提示，不代表对应的功能子目录已经建好——子目录仍需用户手动建或明确指示AI创建
